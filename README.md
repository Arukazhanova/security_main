# Security Site Backend

Backend-приложение для дипломной работы: система регистрации, авторизации, подтверждения email, восстановления пароля и администрирования пользователей.

Проект реализован на Spring Boot с использованием Spring Security, JWT, refresh token, PostgreSQL и email-уведомлений.

---

## Основной функционал

В проекте реализованы:

- регистрация пользователя;
- авторизация пользователя;
- access token и refresh token;
- обновление access token через refresh token;
- logout с отзывом refresh token;
- JWT-аутентификация;
- подтверждение email;
- повторная отправка письма подтверждения;
- восстановление пароля через email;
- сброс пароля;
- просмотр профиля пользователя;
- обновление профиля пользователя;
- смена пароля;
- разграничение доступа по ролям USER и ADMIN;
- админ-панель API;
- просмотр списка пользователей администратором;
- блокировка и разблокировка пользователей;
- изменение роли пользователя;
- защита от доступа USER к ADMIN endpoint-ам;
- защита от блокировки самого себя;
- защита от изменения собственной роли;
- защита от удаления последнего администратора.
